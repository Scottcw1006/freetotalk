- **O10** → 任務 2 驗收 2：R＝正常回覆。T0；讚 → 「『已讚』恰好讀到一次，而且落在 R 的範圍內；R 的文字與 T0 逐碼位相同」；截圖 R 有標記、別則沒有；再長按 → 「恰好『複製』『取消讚』『刪除』」。取消讚 → 「整個聊天畫面讀不到『已讚』」、截圖無標記、文字仍 T0、長按「恰好『複製』『讚』『刪除』」。關選單：讚 R → 長按 → 點外面；長按 → BACK →「仍在聊天畫面，『已讚』仍恰好讀到一次、在 R 上」。

- **O12** → 任務 2 驗收 4：讚了與沒讚的同畫面截圖 → 「標記在讚了的那則泡泡之內或與它相接，不與相鄰的泡泡相接；沒讚的泡泡上沒有」；深色模式再截 →「標記看得出來」；判完切回。
