# 如果 fail：問題歸屬

本輪沒有 fail。下面幾點給 PM 參考，都不構成打回：

1. **任務 2 驗收 3 預期 4「留下切換當下已經顯示的文字」的證據不完整。**
   - 切換這個動作本身（打開選單或抽屜再點）要 0.8–1 秒，這段時間裡回覆還會再長。
   - 所以「切換前最後一張截圖的文字」與「A 裡留下的文字」必然不同：A 比截圖長，而且以截圖內容為開頭。
   - 本輪能判到的是「保留了切換時已有的內容（截圖內容是前綴）加上中斷標記、不是錯誤訊息」。條文字面上的「當下」，現場沒有可以逐字比對的證據。本輪以「結尾是中斷標記」判定（這正是條文「這一次算不算數」寫的判法）。
   - 建議 PM 考慮把預期 4 的判法寫成「以切換前畫面上的文字為開頭、以中斷標記結尾」。
2. **任務 3 驗收 1「排在最前」**：本輪用的是只出現在 N 開場白裡的詞，結果只有 N 一組，「排在最前」自然成立。條文沒有要求那個詞也要出現在其他段，所以判 pass；但這樣的測資照不出排序錯誤。如果這一點重要，建議條文指定「那個詞同時出現在已存的其他段」。
3. **模擬器上的串流很短**（Gemma／SmolLM 約 3–4 秒就撞到長度上限或迴圈偵測，Qwen 也在數秒內結束）。任務 2 驗收 3、任務 7 驗收 1、13、14 都有幾次嘗試因此不算數，已依條文重做。本輪沒有出現「本環境無法觀察」。

# 本輪隨機抽測的三項功能

- **搜尋-08**（一段對話命中超過三則時，那一組下面多一行「還有 N 則符合」）
  - 做了什麼：在一段對話裡送出 4 則含 `zulu` 的訊息，搜尋 `zulu`。

- **搜尋-18**（離開搜尋會把打的字清掉）
  - 做了什麼：分別用左上角箭頭、手機返回鍵（先確認鍵盤已收起）、點命中列三種方式離開，再從抽屜進入。

- **保存-02**（沒說過話的對話不存；外面寫入的無使用者訊息對話會出現、打開再離開就清掉、不另外提示）
  - 做了什麼：連開兩次新對話（都不說話），然後在資料庫寫入只含助理訊息的一段，冷啟動，點開它，再開新對話離開。
  - 看到什麼：
    - 連開兩次新對話後，抽屜列數不變，沒有「還沒說話」的列。
