# 如果 fail：問題歸屬

1. **任務 1 驗收 1 → 主要打回 RD**：round-trip 測資的 `model` 用了預設值 `Gemma1B`，讀取端把模型漏轉（直接給 `ModelSpec.Default`，或讀錯欄位再退回預設值）時，這支測試不會變紅。修法是換成非預設的模型。產品行為本身在裝置上沒有問題：P1 用 Gemma、其餘用 Qwen 與 SmolLM，讀回的模型標示都正確。
