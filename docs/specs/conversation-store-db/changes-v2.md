# 這一輪改了什麼

v1 列的四項待決（D1–D4）與 D4 的子題已由使用者拍板，另有一筆「資料庫用 Room」的使用者指定、一筆 RD 的存檔設計回報。**`spec-decisions.md` 回到 0 項，RD 可以開工。**

**合起來動到了根本假設，先講這三件**：

- **資料庫層不寫自動化測試**（使用者開的例外），純邏輯照常測；
- **測資分兩條路**：App 做得出來的用正常操作建立，做不出來的才直接改資料庫檔；
- **另兩份規格不回頭改**，改以兩份全域文件為準。

架構建議 §B.1、§G、§H 改寫，新增 §I。

**v1 沒有交給 RD、也沒有驗收過，仍然開 v2**：v1 是使用者做這幾項裁決時看的那一版。
