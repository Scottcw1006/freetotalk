# 這一輪改了什麼

**沒有新功能、沒有 bug、沒有要求任何實作改動。** 起因是收件匣三筆使用者裁決：**決策 I 選 (a)**、**決策 J 選 (c)**、**驗收環境可以清空裝置上的 App 資料**。

動到三個方面：**`spec.md` §5.2 改寫成列出抽屜該有的東西**（決策 I）；**`spec.md` §9.1 補上「既有的空白對話檔打開再離開就清掉」，任務 16 從 bug 修正改成把現況寫下來**（決策 J）；**拿掉一句預設要保護真實資料的話**（環境）。兩個決策連同選項表移進附錄，`spec-decisions.md` 回到 **0 項**。

**入口檔是 `v3.15/spec.md`。** 本輪的定版目錄是 **`v3.15/`**（由 `v3.14/` 用 `cp -r` 複製後修改）。**為什麼不在 v3.14 裡改**：v3.14 雖然還沒被驗過，但它是使用者拍板時看的那一版，留著它才對得出兩個決定前後差在哪。**`v3.14/` 以前一個字都沒有動。**

**`docs/product/features.md` 本輪改了一格：保存-02**（描述補上髒資料的例外，「對應 spec」改指 `spec.md` §9.1「儲存一段空白對話等於刪檔，不是寫檔」）。
