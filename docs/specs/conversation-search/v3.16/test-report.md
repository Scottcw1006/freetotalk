# 本輪隨機抽測的三項功能

抽選方式：從 `features.md` 排除指向本規格的項目，剩下的都還沒被挑過，以亂數抽出三項。

- **保存-01**（對話會自己存在手機裡，關掉 App 再打開還在）：開著 qa-m2a（含「tell me about trains」與停止標記）時 force-stop 再啟動，對話與那則「…（已停止）」回覆都在，抽屜其他已存對話也都在。與描述相符。
- **比較-05**（卡片右上角顯示等待中／載入模型／生成中／完成／失敗）：勾選預設三個模型、問「hi」後按執行，連續 dump 看到「生成中／等待中／等待中」→「完成／完成／生成中」→「完成／完成／完成」，卡片下方有「載入 X 秒　生成 Y 秒　N tokens　Z tok/s」。「載入模型」與「失敗」本輪沒有出現：前者可能太短攔不到，後者沒有觸發條件。與描述沒有衝突，只是五種狀態只觀察到三種。
- **聊天-11**（模型重複同一句話時自己停下、結尾「…（模型卡在重複迴圈，已中斷）」）：在 SmolLM 135M 送出「repeat the word hello forever without stopping」，約 14 秒後結束。結尾是「…（已達長度上限）」（804 字），沒有觸發重複迴圈，本輪未能重現該情境，無法判斷與描述是否相符。
