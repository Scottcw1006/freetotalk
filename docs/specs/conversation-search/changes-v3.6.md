# 未改動但與本輪改動互相牽動的章節

- **§8.1 與 §8.2 要一起讀。** §8.2 少掉一項不是漏寫，理由寫在 §8.1 底下那段註記，兩處只有合起來才看得懂。
- **§G.1（「什麼算一次更新」只有一個定義處）** —— 沒有改，但它是「本輪不需要任何實作改動」的原因：那個定義處以「內容是否相同」判斷，沒有停止的特例，所以規則從線的一邊換到另一邊，程式什麼都不必動。**RD 若發現實作裡真的有一個針對停止的排除，那才是要改的東西。**
- **§6.4 的實作註記** —— 沒有改，但新的 §6.5 條文明列「空值防護不算違反」，而那個防護正好就是這段註記描述的路徑。**兩者要一起讀，否則會誤以為那句「看起來剛好無害」的警告被放寬了**（它沒有）。
- **任務 8 驗收 5、13** —— 沒有改，但它們與驗收 14 是同一組：5 管「有沒有改到磁碟」、13 管「判準是不是 id」、14 管「有沒有特例分支」。改寫的是 14 的判定方式，另外兩條照舊。
- **§F.2 與 §F.3** —— 沒有改，但新增的 §F.6 是同一族（規範 QA 怎麼判定）。差別是 §F.1–§F.3 明寫「不另立條文」（它們沒有可觀察物），而 §F.6 有一個：驗收記錄裡那項證據。
- **§4.2 與任務 3 驗收 23** —— 沒有改。本輪只把 §4.2 的 off-by-one 當成 §F.6 的舉證（那次實機驗到的是還帶著它的舊建置）。**條文與規則都不受影響。**
