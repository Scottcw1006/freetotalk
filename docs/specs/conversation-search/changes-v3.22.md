**結論：沒有缺口，本輪不需要補條文。** 兩件誠實寫下來的事：

1. **§2.8(a) 的「長按空白鍵」「貼上單一 U+3000 / U+00A0」兩個案例，在畫面上仍可能做不出來。** 本輪讓這個退路變得**更難被濫用**（沒有寫清楚失敗在哪一步就是 fail），但**沒有讓它消失** —— 那兩個案例是不是真的做不到，仍然只有走到那一輪的人知道。
2. **任務 19 守的不是 §1–§9 的任何一條規則。** 這是刻意的，和任務 10（守 `plan/architecture.html`）、任務 15（守那份清單指向本規格的引用）同一個形狀：守的是文件之間讀不讀得對。它仍然答得出「被違反時使用者會遇到什麼」—— 那份清單對「哪些功能還沒有人確認過」的回答會是錯的。
