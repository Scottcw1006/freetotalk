# 本輪掃描的界線（哪些數量拿掉、哪些留著）

**這是我畫的界線，不是使用者定的**，寫出來讓下一個人能照同一條線判：

- **拿掉**：會被**別人在另一輪**改掉而自己變錯的東西 —— 測試檔的數量、既有條文的數量、另一輪那個字串的字元數、指向已經不存在的檔名、以及本文自己列表長度的計數。
- **留著**：描述**一件已經結束的事**、而且**在同一個地方就列得出來**的數量（例如 v3.5 那次補掃掃過幾條規則、補了哪幾條條文）。它們是一個封閉集合的性質，別人改東西不會讓它們變錯。
- **刻意沒動**：**任務 10 的執行紀錄**（那是決策 E 未決的那一半，動它等於替使用者做決定）、以及 **`docs/product/features.md`**（跨輪、剛被另一輪動過，本輪沒有非改不可的理由）。
- **殘留風險**（也寫進了 `spec-appendix.md`／已知取捨）：這次是人工掃的，沒有機制保證掃乾淨；留著的那些歷史數字，若有人拿去當現況用一樣會誤導。
