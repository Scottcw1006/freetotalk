# 這一輪改了什麼（v3.5）

起因有兩件：(1) 使用者裁決**決策 B = 選項 (d) + 一次性補掃** —— 「規則 → 條文」的反向核對升格成硬性條文，但每輪只掃被改動的章節，並先把政策生效前的歷史債清一次；(2) 本輪進行中收件匣又進來一筆 RD 觀察（§8.2 第三點對「按下停止」的事實宣稱不成立），我讀過程式碼確認後**升級成兩項待決事項**。

**這一輪沒有改動任何一條規則的字面。** 新增的全部是「可判定條文」、「由哪一層守」的註記、一條流程性的架構條文（§F.5），以及一個警示框。

**入口檔仍是 `spec.md`**，五份檔案的分法沒有改變。
