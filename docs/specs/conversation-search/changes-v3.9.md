§A.3（截斷屬純邏輯）、§A.6（畫面顯示的兩個數字必須等於 §3.4 定義的值）、§B.1（搜尋輸入是看得到的那些對話）、§B.3（合併語意：留哪一份、排序位置）、§C.1（步驟順序 → 含換行訊息的標示位置）、§C.2（折疊長度不變）、§C.3（兩端同一正規形式）、§C.6（空查詢用同一份整形）、§C.8（欄位規則與空白定義同源）、§D.1（輸入框在捲動容器頂端）、§D.4（旋轉撐得過、行程死亡不必）、§D.5（返回鍵與旋轉的行為差異）、§E.7（空白對話刪檔、壞檔容錯）、§G.2（時間是內容的性質）、§G.3（不改寫檔時機）。
