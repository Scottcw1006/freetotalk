13. **查詢被清空時回到引導文案要不要也等 250 毫秒，規格不規定。** 你的原話講的是「開始搜尋」，清空不是開始一次搜尋；立刻回去或等 250 毫秒再回去，使用者幾乎分不出來，兩種都通過驗收（判讀點在輸入停止 1 秒後）。
