# 未改動但與本輪改動互相牽動的章節

**這些沒有被我改過，但這一輪很容易在它們上面出錯：**

- **R1（停止不是錯誤）的禁止字串清單。** 新標記必須不觸犯它。**我已經核對過：`…（已停止）` 不含 `cancel`/`Cancel`/`Exception`/`Job`/`Coroutine`，兩條不衝突** —— 不必再查一次。
- **R8（兩種自動中斷一字不得改）。** 新標記刻意做成與那兩個同形（同一個刪節號字元、全形括號、直接接在文字後）。**同形不是「順手統一」的邀請** —— 不要為了對齊新標記而去動那兩個既有字串，動了就是 R8 fail。
- **R4（零文字時整則不留）。** 它是 R2 的邊界：R2 只管「已經有文字」的情況。兩條合起來才是完整的答案，也是 R11 無條件成立的依據。
- **任務 3（落盤）。** 存進檔案的文字現在含標記，所以任務 3 驗收 2（force-stop 後文字與停止時相同）**要連標記一起比對**。
- **任務 4 驗收 5（搜尋）。** 「停止之後那則部分回覆的文字必須搜得到」現在也包含標記本身；搜「已停止」會命中被停止過的對話。**這是預期行為，不是 bug**（S1 選項 (b) 的代價欄裡明寫過，使用者看過才選）。
- **任務 4 驗收 6（`conversation-search` §8.3、§8.4 仍通過）。** 這兩條與 S1 無關，照原樣執行。**但 §8.6 不在這條裡，也不要自己加進來** —— 理由見已知衝突第 5 條。
